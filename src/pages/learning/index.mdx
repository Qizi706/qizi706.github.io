<section id="method" class="roadmap-section">

## 所有 Lab 使用同一个闭环

系统 Lab 被拆成连续小步，每一步先产生可失败的测试，最后用自动验收和闭卷解释完成 Checkoff。

- <strong>Question：</strong> 明确本轮只回答一个可以被证伪的问题。
- <strong>Prediction：</strong> 运行前写 Shape、趋势、状态变化或失败边界。
- <strong>Pre-read：</strong> 只阅读马上会用到的章节、接口和源码文件。
- <strong>Implement：</strong> 一次只增加一个变换，并先写最小失败测试。
- <strong>Grade：</strong> 通过定向测试、完整回归和原始数据审计。
- <strong>Checkoff：</strong> 关闭代码复述机制，记录修正规则，再解锁下一层。

</section>

<section id="materials" class="roadmap-section">

## 每种材料只承担一种职责

- <strong>Syllabus — 学习总路线：</strong>
  回答“先学什么、为什么、通过后解锁什么”；本页是唯一跨阶段入口。
- <strong>Lab README — 使用入口：</strong> 稳定说明怎样下载、启动、评分以及公开 Starter
  与本地实现分别位于哪里。
- <strong>Assignment — 当前任务书：</strong> 只回答当前 Gate
  的准备、边界、实现要求、提示和评分命令。
- <strong>Notebook — Gate 工作表：</strong> 保存预测、第一次失败、修正规则、结果与
  Checkoff，不重复任务说明。
- <strong>Evidence — 测试与 results：</strong>
  保存自动验收、原始样本和可重建结果，是实验结论的事实源。
- <strong>Textbook — 机制文章：</strong> 建立稳定概念模型；阅读用于形成预测，但不能替代 Lab。
- <strong>Report — 实验文章：</strong> 只总结已经产生的证据、失败和适用边界，不承担进度追踪。
